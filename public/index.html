Como o GoLiveBack funciona?

O GoLiveBack prepara uma rota externa somente para a parte do Discord responsável pela conexão do Go Live e da câmera. Ele não altera arquivos nem instala complementos no Discord.

  • 1. Encontra uma saída seguraO Tor integrado procura uma conexão válida fora do Brasil. Se você preferir, também pode usar uma proxy própria.
  • 2. Proxy própria exige confiançaEm uma proxy SOCKS5 remota, usuário e senha não possuem criptografia própria. Prefira uma proxy local ou conectada por um túnel protegido.
  • 3. Cria uma rota localUm proxy SOCKS5 e um pequeno arquivo PAC direcionam apenas os endereços necessários do Discord para essa saída.
  • 4. Reabre o Discord protegidoAo usar “Reiniciar Discord”, o cliente volta a abrir sabendo que deve usar a rota preparada pelo GoLiveBack.
  • 5. Mantém tudo funcionandoUm monitor verifica a rota periodicamente e tenta recuperá-la se a conexão for interrompida.

Áudio, vídeo, downloads e o restante da navegação continuam usando sua conexão normal.
